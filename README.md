# Bombay Silvers

Enterprise Dealer Management Platform for Bombay Silvers.

## Features

- Dealer Portal
- Live Inventory
- Order Management
- Ledger
- Invoices
- KYC
- Referral System
- Role Based Access Control
- Row Level Security

## Tech Stack

- React
- TypeScript
- TanStack Router
- TailwindCSS
- Supabase
- PostgreSQL

## Security

- Row Level Security
- RBAC
- Audit Logging
- IDOR Protection
- Soft Deletes

## Installation

npm install
npm run dev
