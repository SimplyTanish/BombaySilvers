# Overview

Bombay Silvers is a dealer-focused business management platform designed for precious metal wholesalers.

Unlike a traditional e-commerce website, this platform serves as the operational backbone for dealers, staff and administrators by providing secure inventory management, order processing, ledger management, KYC verification and analytics.

The application is designed with enterprise-grade security using Role Based Access Control (RBAC) and PostgreSQL Row Level Security (RLS).
